# MakeThemFall

MakeThemFall in Unity 2D

https://onurp.itch.io/makethemfall

It is a clone of the game Make Them Fall, where you tap the screen to move characters from one wall to another, avoiding obstacles and collecting points.

Make Them Fall oyununun klonudur; ekrana dokunarak karakterleri bir duvardan diğerine geçirip, engellerden kaçarak puan topladığınız bir oyundur.
